# Overview
This Jupyter Notebook analyzes the transcript of Avatar The Last Airbender Season 3 Episode 21. The code is written in Python.

# Files
1. **Avatar_S3_E21_Transcript.txt:** Contains the transcript (taken from https://avatar.fandom.com/wiki/Transcript:Sozin%27s_Comet,_Part_4:_Avatar_Aang)
2. **requirements.txt:** Contains the Python package requirements for the notebook
3. **Avatar_The_Last_Airbender_S3_E21.ipynb:** Contains the notebook

# Instructions
If anyone wants to run the notebook themselves:

## Option 1
1. Download the transcript and notebook files and place them in the same folder
2. Open the notebook in JupyterLab/Jupyter Notebook
3. Run the notebook

1. Open the binder link to run the notebook online without needing to install JupyterLab/Jupyter Notebook:
